## Part 3: Code Does Not Live Alone
Explain how code connects to soft skills, hard skills, collaboration, machines, documentation, and communication.
Building this project required more than just writing VB.NET code. I had to use organization skills to create a clear folder structure, keep my files in the correct locations, and make sure my submission was easy to follow. Problem-solving was important because I ran into errors with file paths, variables, duplicate procedures, and JSON saving. I had to read error messages, test different solutions, and make changes until the program worked correctly. Communication also connected to the project because I needed to explain my process clearly through the reflection, screenshots, GitHub files, and Discord progress post. The code depended on tools and machines such as Visual Studio, the computer’s file system, and GitHub, so all of these parts had to work together for the project to be complete.


## Part 4: What I Would Change
If you could redo Weeks 6-8, what would you organize, document, ask, test, or submit differently?
If I could redo Weeks 6–8, I would organize my project files and folders earlier so everything stayed easier to manage throughout development. I would test my code after completing each feature instead of waiting until several changes were made, which would make it easier to identify and fix errors. I would also write comments as I coded instead of adding them at the end, making the code easier to understand. Finally, I would spend more time planning the JSON structure before implementing it to avoid making changes later and create a more organized application.
